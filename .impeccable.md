## Design Context

### Users
Long-distance couples (LDR) who want a private, shared digital space. They use this daily — checking in, answering a question together, sharing photos, reading scripture. The emotional context is longing, love, and the anticipation of reunion. This is not a social app; it's intimate and personal. The user wants it to be used by LDR couples broadly, not just as a personal project.

### Brand Personality
**Premium, polished, refined.** The interface should feel like it was thoughtfully crafted — not AI-generated, not a startup template, not a consumer social app. Three words: **intimate, elevated, still**. It should feel calm and beautiful to open, like a love letter rather than a notification feed.

### Aesthetic Direction
- **Theme**: Light mode. Warm cream backgrounds, soft purple accent palette (#C4B5E0, #9B88C8), dark navy text (#2B3A4A).
- **Typography**: Plus Jakarta Sans is in use and fits well. Should be used with restraint — tight hierarchy, no decorative overuse.
- **Icons**: Simple, clean icons only. No icon + heading + text card templates. No emoji as decoration (emoji used emotionally is fine, e.g. 💜 in the thinking button).
- **Complexity**: Fun but restrained. The interface should not feel busy. Every element earns its place.
- **Anti-references**: Dating apps (gamified, cheap), generic AI UI (dark mode + glowing purple), social media feeds (attention-extracting), productivity apps (gray, corporate).
- **Purple theme**: The existing purple should stay. It's the brand color. Use it with purpose, not decoration.

### Design Principles
1. **Restraint over decoration** — If an element doesn't serve the user, remove it. No visual noise.
2. **Emotion through craft, not ornament** — The app should feel romantic because it's beautiful and intentional, not because it has hearts everywhere.
3. **Premium means consistent** — Spacing, type sizes, and colors should follow a system. No one-off values scattered throughout.
4. **Privacy as design value** — The interface should feel like a private space. Nothing should feel public-facing or social-network-like.
5. **Clarity before delight** — Users must always know where they are, what to do next, and what happened. Only then add moments of delight.
